# Etude downloads

Windows installers and updates for Etude, a chess training app.

## Get updates

[Download Etude-Updater.exe](https://github.com/jcorr92/etude-downloads/releases/latest/download/Etude-Updater.exe)

Keep this small executable and run it whenever you want the latest version.
Close Etude first, then choose **Download and install** and finish the installer.
Your saved progress, settings and imported courses are kept. There is no
uninstall or reset step.

## First install

[Download the latest Windows installer](https://github.com/jcorr92/etude-downloads/releases/latest)

Download the `Etude.Setup` executable and run it on Windows (x64).
The updater also works for a first install.

This repository hosts installers and release notes. Development takes place in a separate repository.
